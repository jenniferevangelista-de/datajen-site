Traduzindo para o dia a dia

Este detector recria a introdução de Spark e AWS na análise de vendas da Dafiti. PySpark processa o volume distribuído e o modelo compara cada cenário com o comportamento esperado para apontar desvios; para o negócio, evidencia onde investigar estoque, campanha ou operação antes que uma anomalia vire uma decisão equivocada.

O que faz: Modelo Spark detecta quando vendas caem fora do padrão esperado. Experimente: escolha cenário (Black Friday/normal), simule checagem, compare. O que a demo mostra: como um alerta sintético pode orientar investigação de uma variação nas vendas.
Spark e AWS como alavancas de escala

Jennifer levou processamento distribuído para a engenharia de dados da Dafiti.

Esta reconstrução mostra a modernização de cargas antes concentradas em consultas BigQuery para pipelines PySpark no Amazon EMR, com dados no Amazon S3 e orquestração Airflow. A mudança abriu espaço para processar volumes maiores, reduzir gargalos e incorporar detecção de anomalias à operação de e-commerce.
